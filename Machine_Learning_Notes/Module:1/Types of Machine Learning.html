01 / Supervised Learning

Learning from labeled examples

Every training example already comes with the correct answer attached. The model studies many such input→answer pairs until it can predict the answer for data it has never seen.

Example: a spam checker is trained on emails already marked Spam or Not Spam. When a brand-new email arrives, the trained model predicts which bin it belongs to.
  • Needs labeled data: input + correct output together
  • Used for prediction tasks — classification & regression
  • e.g. Linear Regression, Logistic Regression, KNN

02 / Unsupervised Learning

Finding structure with no labels

The data has no correct answers attached at all. The algorithm looks at the data on its own and groups similar items together, without ever being told what the groups should be.

Example: a shop clusters its customers by habit and discovers three natural groups — Big Spenders, Bargain Shoppers and Occasional Buyers — without anyone defining those labels first.
  • No labels needed — the structure is discovered, not given
  • Used for clustering & pattern discovery
  • e.g. K-Means, Hierarchical Clustering

03 / Semi-Supervised Learning

A few labels guide the rest

Only a small part of the data is labeled; the rest is not. The model uses the few labeled examples as anchors and spreads that understanding across the much larger unlabeled pool.

Example: in a photo album, only 2 of the 16 photos are tagged with names. The model learns what each person looks like from those few tags and labels the rest of the album automatically.
  • Mix of a little labeled data + a lot of unlabeled data
  • Useful when labeling everything by hand is slow or costly
  • e.g. label propagation, self-training

04 / Reinforcement Learning

Learning by reward and penalty

There is no fixed dataset of correct answers. An agent takes actions in an environment, earns rewards for good moves and penalties for bad ones, and slowly learns the strategy that scores the most over time.

Example: a robot explores a maze. It tries a few paths, loses points for hitting hazards, then learns the route that collects coins and reaches the flag for the highest score.
  • No labeled dataset — learns purely from trial and error
  • Goal: maximize total reward over time, not just one step
  • e.g. game-playing agents, robotics, self-driving cars
